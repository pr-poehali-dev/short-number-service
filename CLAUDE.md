# Предпочтения и контекст проекта 2407.рф

## О проекте
Справочник коротких номеров России. SPA на React + TypeScript + Vite.
Двуязычный (RU / EN). PWA-ready.

## Стек
- React 18, TypeScript, Vite, Tailwind CSS 3
- shadcn/ui + Radix UI (компоненты)
- React Router DOM 6 (роутинг)
- Lucide React (иконки через обёртку `<Icon name="..." />`)
- Oswald (заголовки, `font-display`) + Golos Text (текст, `font-body`)

## Структура
```
src/
  App.tsx                   — точка входа, роутинг
  pages/
    Index.tsx / IndexEn.tsx — главные страницы RU/EN
    SharedComponents.tsx    — Header, NumberCard, NumberModal, InstallModal
    DirectorySection.tsx    — справочник
    HomeSection.tsx         — главная секция
    data.ts / data-en.ts    — данные номеров
    useFavorites.ts         — хук избранного
  components/ui/            — shadcn компоненты
  lib/
    utils.ts                — cn()
    analytics.ts            — Яндекс Метрика (ymGoal)
```

## Цвета (CSS-переменные, HSL)
- `--primary`: 217 72% 28% — основной тёмно-синий
- `--accent`: 211 100% 50% — яркий синий
- `--brand-orange`: 25 95% 53% — акцент
- Цвета операторов: red (МТС), yellow (Билайн), green (МегаФон), sky (Т2), purple (универсальный), amber (коммерческий)

## Паттерны кода
- Классы объединять через `cn()` из `@/lib/utils`
- Иконки только через `<Icon name="..." />` из `@/components/ui/icon`
- CVA для вариантов компонентов
- Аналитику трекать через `ymGoal()` из `@/lib/analytics`

## Предпочтения владельца (из чатов)

### Навигация / Header
- На мобильных (md:hidden) кнопки навигации скрыты в гамбургер-меню
- В разделах "Справочник" и "Быстрый ответ" в шапке показывается кнопка перехода в противоположный раздел (только мобильные)
- Кнопка-переключатель позиционируется абсолютно по центру шапки (`absolute left-1/2 -translate-x-1/2`), чтобы не смещаться при переключении
- Шапка на ПК: `grid grid-cols-[1fr_auto_1fr]` — логотип слева, nav по центру, кнопки справа (без смещений)
- Шапка на мобильных: `flex justify-between` — логотип слева, кнопки справа
- На кнопке EN — без иконки глобуса

### Общие предпочтения
- Минимум комментариев в коде
- Не менять то, что не просили — точечные правки
- Версия для ПК и мобильная версия разрабатываются независимо — изменения в одной не должны ломать другую
- Перед правкой шапки всегда проверять, что мобильная и десктопная версии не мешают друг другу
